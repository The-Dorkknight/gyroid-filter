Cura plug-in

Installs the Gyroid Filter tool into Cura. Afterwards: select a model in Cura, pick the Gyroid Filter tool on the left, click a face or cylinder.

Work in progress: this plug-in has been run inside a real Cura on Linux Mint and works well. Windows and Mac are not tested yet. Please report what happens.

About

Gyroid Filter __VERSION__ · built __BUILD__ · source-available, non-commercial (PolyForm Noncommercial 1.0.0), no warranty.

It never changes your original model. It builds extra "region" volumes that your slicer prints as open-cell gyroid (no walls, no skin), so air can pass through while carbon granules stay in.

Not a medical or safety device. Check that your printed filter suits what you filter; PLA/PETG are not rated for food, chemicals or high temperatures.
